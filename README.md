# لوحة التحكم لعضو الفريق التنفيذي — لوحة التحكم للمدارس المسندة

تطبيق ويب تقدّمي (PWA) عربي يعمل دون اتصال لمتابعة المدارس المسندة لعضو الفريق التنفيذي: بيانات المدارس، دخول المعلمين والطلاب لمنصة مدرستي، نسب الغياب، أعمال المشرف، خطة الزيارات الأسبوعية والملخص الشهري، والتقرير الأسبوعي بالنموذج الرسمي.

- 🔒 **البيانات على الجهاز فقط** (IndexedDB) — لا يوجد أي رفع سحابي. نسخ احتياطي JSON + نسخ تلقائية على الجهاز + طلب التخزين الدائم.
- 📥 استيراد ملف الإكسل «لوحة التحكم للمدارس المسندة» داخل المتصفح دون اتصال.
- 📤 تصدير Excel (SheetJS مضمّنة محلياً) وطباعة / PDF.
- لا يحتوي المستودع على أي بيانات حقيقية؛ البيانات التجريبية وهمية بالكامل ومعلَّمة بذلك.
